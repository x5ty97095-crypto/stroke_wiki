# `/topic-slides` Input 模板（直接複製修改）

## 模板 A：初學者教學型（預設模式）

```text
/topic-slides 急性缺血性中風靜脈溶栓治療（AIS IVT）

【簡報設定】
- 目標受眾：不熟悉此主題的初學者（避免未經解釋的專業術語，必要時用白話或類比輔助）
- 簡報類型：教學型簡報（強調概念建立、因果邏輯與循序漸進的學習路徑）
- 預計篇幅：約 8–10 頁（含封面與重點回顧頁）
- 視覺偏好：多利用流程圖、對照表或步驟拆解，幫助初學者建立心理模型
- 必含範圍：時間窗（0–4.5h 與延長窗）、TNK vs Alteplase 比較、關鍵禁忌與安全紅線
```

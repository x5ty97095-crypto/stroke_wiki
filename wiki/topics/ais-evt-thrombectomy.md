# 急性缺血性中風血管內機械取栓（AIS EVT）

> [!tip] 臨床速查結論（Bottom Line）
> - **不可跳過 IVT，不可等待觀察**：同時符合 IVT 與 EVT 者應儘速給 IVT 且**不觀察臨床反應、不延遲動脈穿刺**（COR 1, LOE A，[[aha-asa-ais-2026|AHA/ASA AIS (2026)]] Sec 4.7.1）。
> - **急診血管影像勿等腎功能**：24h 內疑似 LVO 儘速執行頸部/顱內 CT/CTA 或 MRI/MRA（COR 1, LOE A），**不應等血清 Creatinine**（COR 1, LOE B-NR，Sec 3.2）。
> - **前循環 ICA / M1 強推薦（COR 1, LOE A）**：
>   - `0–6h`：NIHSS ≥6、prestroke mRS 0–1、**ASPECTS 3–10**（正式納入大梗塞核心 ASPECTS 3–5）。
>   - `6–24h`：NIHSS ≥6、prestroke mRS 0–1、**ASPECTS ≥6**；或**精選病患 ASPECTS 3–5**（年齡 <80 歲、無顯著 mass effect）。
> - **超核心與既有失能（COR 2a）**：`0–6h` 精選 **ASPECTS 0–2**（<80 歲、無顯著 mass effect，COR 2a, LOE B-R）；`0–6h` **prestroke mRS 2** 且 ASPECTS ≥6（COR 2a, LOE B-NR）。
> - **基底動脈阻塞（BAO）強推薦**：`0–24h`、baseline mRS 0–1、**NIHSS ≥10**、**PC-ASPECTS ≥6**（COR 1, LOE A，Sec 4.7.3）。
> - **中遠端血管（MeVO）不建議常規取栓**：非優勢/共優勢近端 M2、遠端 MCA、ACA、PCA 屬 **COR 3: No Benefit, LOE A**（僅優勢近端 M2 0–6h 為 COR 2a, LOE B-NR）。
> - **取栓前後血壓目標與紅旗**：未 IVT 者術前維持 `≤185/110`、術中/術後 24h 維持 `≤180/105`（COR 2a）；**前循環 LVO 成功再通（mTICI 2b/2c/3）後 72h 內積極降 SBP <140 mm Hg 有害且禁用**（**COR 3: Harm, LOE A**；詳見 [[ais-bp-glucose-supportive|AIS 血壓與支持處置]]）。

## 1. 成人 EVT 適應症與時間窗決策總表（[[aha-asa-ais-2026|AHA/ASA AIS (2026)]] Sec 4.7.2–4.7.3）

| 阻塞部位 | 時間窗 | 臨床與影像篩選條件 | COR / LOE | 關鍵試驗與臨床註記 |
| :--- | :--- | :--- | :--- | :--- |
| **前循環 ICA / M1** | **0–6h** | NIHSS ≥6、prestroke mRS 0–1、**ASPECTS 3–10** | `COR 1, LOE A` | HERMES（≥80 歲仍有效 cOR 3.68）＋大核心 RCT（ASPECTS 3–5 之 NNT=8；功能獨立 19.5% vs 7.5%，獨立行走 36.5%；大核心應與家屬充分討論期望） |
| **前循環 ICA / M1** | **6–24h** | NIHSS ≥6、prestroke mRS 0–1、**ASPECTS 6–10** | `COR 1, LOE A` | DAWN（NNT=2.8）、DEFUSE-3（NNT=3.6）、AURORA（a-cOR 2.54）；立即取得時輔助 CTP/MRI 可有幫助（COR 2a, LOE A），但 NCCT vs CTP 功能獨立率在 CLEAR/Meta-analysis 無顯著差異 |
| **前循環 ICA / M1（大核心精選*）** | **6–24h** | **年齡 <80 歲**、NIHSS ≥6、prestroke mRS 0–1、**ASPECTS 3–5**、**無顯著 mass effect** | `COR 1, LOE A` | SELECT2、ANGEL-ASPECT。*外推限制：>80 歲、腎衰竭、難治高血壓 ≥185/110、干擾評估共病、壽命 <3 個月。SELECT2 探索分析提示嚴重低密度（≤26 HU）≥26 mL 者無功能獲益且水腫/開顱風險升 |
| **前循環 ICA / M1（極大核心精選†）** | **0–6h** | **年齡 <80 歲**、NIHSS ≥6、prestroke mRS 0–1、**ASPECTS 0–2**、**無顯著 mass effect** | `COR 2a, LOE B-R` | LASTE（多以 MRI-DWI 篩選於 6.5h 內；功能獨立 13.3% vs 7.5%）。†排除 ≥80 歲、血管嚴重扭曲、發作癲癇干擾評估、高度懷疑 ICAS、壽命 <6 個月 |
| **前循環 ICA / M1（輕度原有失能）** | **0–6h** | NIHSS ≥6、ASPECTS ≥6、**prestroke mRS = 2** | `COR 2a, LOE B-NR` | HERMES 7-RCT 統合（mRS 1–2 cOR 2.08），不增加 sICH |
| **前循環 ICA / M1（中度原有失能）** | **0–6h** | NIHSS ≥6、ASPECTS ≥6、**prestroke mRS 3–4** | `COR 2b, LOE B-NR` | 無 RCT；觀察性研究顯示約 20%–32% 可回復原本 mRS |
| **優勢近端 M2** | **0–6h** | 支配 ≥50% MCA 流域之近端 M2（非指左右腦優勢）、NIHSS ≥6、prestroke mRS 0–1、ASPECTS ≥6 | `COR 2a, LOE B-NR` | HERMES M2（aOR 2.39）；但 ESCAPE-MeVO 近端 M2 未分優勢與否為陰性（RR 0.9），效益仍有不確定性 |
| **非優勢/共優勢 M2、遠端 MCA、ACA、PCA** | **0–6h**（及試驗窗） | 中遠端血管阻塞（MeVO/DMVO） | `COR 3: No Benefit, LOE A` | **ESCAPE-MeVO**（mRS 0–1 42% vs 43%；stent retriever 首選死亡率增高 HR 1.82）、**DISTAL**（35% vs 38%） |
| **基底動脈阻塞（BAO）** | **0–24h** | baseline mRS 0–1、**NIHSS ≥10**、**PC-ASPECTS ≥6**（無廣泛腦幹梗塞） | `COR 1, LOE A` | **ATTENTION**（0–12h, N=340；mRS 0–3 46% vs 23%）、**BAOCHE**（6–24h, N=217；mRS 0–3 46% vs 24%） |
| **基底動脈阻塞（輕中度）** | **0–24h** | baseline mRS 0–1、**NIHSS 6–9**、PC-ASPECTS ≥6 | `COR 2b, LOE B-R` | 臨床試驗納入人數極少（BAOCHE 僅 17 例），療效尚未確立 |

> [!info] 兒童 EVT 建議（[[aha-asa-ais-2026|AHA/ASA AIS (2026)]] Sec 4.7.5, 首次納入）
> - **≥6 歲、LVO、0–6h**（由經驗豐富神經介入醫師執行）：`COR 2a, LOE B-NR`
> - **≥6 歲、LVO、6–24h 且具潛在可挽救腦組織**：`COR 2a, LOE B-NR`
> - **28 天至 <6 歲、LVO、0–24h（含首次癲癇發作）且具可挽救組織**（具兒童經驗神經介入醫師）：`COR 2b, LOE B-NR`（新生兒 <28 天無系統證據）

## 2. 術前、術中技術與輔助處置要點（Sec 3.2, 4.7.1, 4.7.4）

| 技術／輔助項目 | 建議內容 | COR / LOE | 關鍵依據與備註 |
| :--- | :--- | :--- | :--- |
| **併用 IVT（Bridging）** | 符合條件者必給 IVT，且不可觀察等待延遲 EVT | `COR 1, LOE A` | 6 RCT 統合分析（≤2h 20m 預計 IVT 優勢顯著）；每延誤 1h 再灌流功能獨立 OR 0.81（ARD −5.2%） |
| **直接送血管攝影室（DTAS）** | 院前高度懷疑 LVO（RACE >4）或院際轉診 LVO（無臨床變化/延誤）可考慮省略傳統急診影像直接 DTAS | `COR 2b, LOE B-R / B-NR` | ANGIOCAT（door-to-groin 18 vs 42 min；cOR 2.2） |
| **第一線器械** | Stent retriever、Contact aspiration 或兩者併用皆推薦 | `COR 1, LOE A` | ASTER、COMPASS、ASTER 2 |
| **血管再通目標** | 儘早達成 **extended TICI（eTICI）2b / 2c / 3** | `COR 1, LOE A` | HERMES |
| **麻醉方式** | **全身麻醉（GA）或意識鎮靜**皆推薦（6–24h 延長窗資料仍不足） | `COR 1, LOE B-R` | AMETIS、DIRECT-MT 亞組 |
| **近端球囊導引導管（BGC）** | 效益不確定 | `COR 2b, LOE B-R` | 觀察統合有利，但 PROTECT-MT RCT 顯示預後較差 |
| **串聯病灶（Tandem Occlusion）** | 急性同時處理顱外＋顱內（含緊急顱外頸動脈支架）可能合理 | `COR 2b, LOE B-NR` | 功能預後較佳但 ICH 風險較高（HERMES、TITAN） |
| **失敗 EVT 之救援成形術／支架** | eTICI 0–2a 時救援氣球擴張／支架效益不確定 | `COR 2b, LOE B-NR` | ANGEL-REBOOT RCT 陰性 vs RESCUE ICAS 觀察正向 |
| **成功 EVT 後輔助 IA 溶栓** | mTICI ≥2b 後輔助 IA Urokinase / Alteplase / TNK 效益不確定 | `COR 2b, LOE B-R` | 試驗結果矛盾：CHOICE 陽性 vs POST-UK、ATTENTION-IA、POST-TNK 陰性 |
| **術前 IV Tirofiban** | EVT 術前給 IV Tirofiban **無益且增 sICH** | `COR 3: No Benefit, LOE B-R` | RESCUE-BT（N=948） |

## 4. 臨床爭議與未解問題
- **6–24h 晚期窗選案影像（NCCT vs CTP）**：CLEAR 與 3 篇統合分析顯示功能獨立率無顯著差異（NCCT 快約 20 分鐘），但觀察資料呈現有利於 CTP 之死亡率訊號，待 NO-SELECT RCT 釐清（Sec 3.2, e345–e346）。
- **大核心嚴重低密度閾值**：SELECT2 探索性分析指出 `≤26 HU 且體積 ≥26 mL` 可能無益且增加腦水腫/開顱需求，尚待前瞻驗證（Sec 4.7.2, e369–e370）。
- **成功 EVT 後輔助 IA 溶栓**：CHOICE 與 POST-TNK / POST-UK / ATTENTION-IA 結果相左，尚無定論。
- **延長窗（4.5–24h）併用 IVT＋EVT**：TIMELESS 未顯示 TNK 優於單獨快速 EVT；0–4.5h TNK Bridging 待 DIRECT-TNK 結果。
- **MeVO 以抽吸優先或較高 NIHSS / 未溶栓族群**：ESCAPE-MeVO 與 DISTAL 主要以 stent retriever 為主且中位 NIHSS 偏低（6–7），特定亞組仍待研究。

# 自發性腦出血住院重症照護、血栓預防與癲癇處置

> [!tip] 臨床速查結論（Bottom Line，[[aha-asa-ich-2022|AHA/ASA ICH (2022)]] Sec 5.3–5.4）
> - **照護場域與神外轉診（Sec 5.3.1）**：專科中風病房／跨專業團隊（`COR 1, A`）；**合併臨床水腦**必轉神外中心（`COR 1`）；中重度（體積 `≥30 mL`）、IVH、水腦或後顱窩出血住**神經專科 ICU** 優於一般 ICU（`COR 2a`）；轉送前氣道/呼吸/循環不穩須先穩定（如 GCS ≤8 插管，`COR 1`）。
> - **DVT / PE 預防與治療（Sec 5.3.3）**：ICH 發生 DVT 風險為 AIS 之 **4 倍**。無法行走者**確診當日啟動 IPC（`COR 1, B-R`）**，**單用漸進式彈性襪無益（`COR 3: No Benefit`）**；**24–48 小時**確認 CT 血腫穩定後可啟動低劑量 UFH/LMWH（`COR 2a/2b`）。若併近端 DVT 尚不適抗凝，放**可回收式 IVC 濾網（`COR 2a`）**，治療性抗凝可延遲 **1–2 週（`COR 2b`）**。
> - **癲癇與腦波（Sec 5.4）**：臨床癲癇或意識障礙併電生理癲癇必給 ASM（`COR 1`）；不明意識波動做 **cEEG ≥24 小時（`COR 2a`）**；**無癲癇證據者禁用預防性 ASM（`COR 3: No Benefit, B-NR`）**（含 Levetiracetam 與 Phenytoin）。
> - **吞嚥、血糖、體溫與心電監測（Sec 5.3.2, 5.3.4–5.3.6）**：經口進食前必做正式**吞嚥篩檢（`COR 1`）**；急診與住院前 **72h** 頻繁神經評估（ICH 超早期惡化 30.8% vs AIS 6.1%）；連續心電監測 **24–72h（`COR 2a`）**；矯正低血糖 **`<40–60 mg/dL`（`COR 1`）**、治療高血糖 **`>180–200 mg/dL`（`COR 2a`）**（避 NICE-SUGAR 嚴控 81–109）；發燒以藥物退燒可能合理（`COR 2b`），低溫 `<35°C` 效用不明（`COR 2b`）。

## 1. 住院分流、轉診與護理監測基準（Sec 5.3.1, 5.3.4）

| 臨床情境與條件 | 處置與場域建議 | COR / LOE | 關鍵數據與實務門檻 |
| :--- | :--- | :--- | :--- |
| **所有自發性 ICH** | 住專科住院單位（Stroke Unit）由跨專業團隊與受神經評估訓練人員照護 | `COR 1, A` / `C-LD` | 瑞典登錄（N=105,043）HR 0.61；標準化醫囑組（**QASC** 發燒/血糖/吞嚥流程）降 90d 死亡失能且 4 年存活增 >20%（`COR 1, B-R`） |
| **無 ICU 適應症之輕中度 ICH** | 住 Stroke Unit 優於一般病房 | `COR 2a, B-NR` | 低轉入 ICU 風險條件：體積 `<20 mL`、NIHSS `≤10`、GCS `≥13`、無/微量 IVH、無未控高血壓或呼吸衰竭 |
| **中重度 ICH（`≥30 mL`）、IVH、水腦或後顱窩** | 住**神經專科 ICU** 優於一般 ICU | `COR 2a, B-NR` | 降死亡率、縮短住院與呼吸器天數 |
| **合併臨床水腦** | 轉送具神經外科能力中心（EVD 置放與監測） | `COR 1, B-NR` | IVH／後顱窩（`COR 2b, B-NR`）與大片天幕上（≥30 mL 或 GCS <8，`COR 2b, C-LD`）轉診亦可能合理 |
| **轉診前不穩定** | 氣道保護/氣體交換/血流動力不足者轉送前應先啟動維生處置（如 GCS ≤8 插管） | `COR 1, C-EO` | 轉院前若不延誤轉送，應先啟動降壓與抗凝反轉（DNAR 不等同放棄緊急治療） |
| **神經護理評估頻率** | 急診超急性期頻繁評估（含 GCS，`COR 1`）；ICU/中風病房至多 **72 小時**頻繁評估（`COR 2a`） | `COR 1` / `2a, C-LD` | 惡化最高峰在前 **12–24 小時**（急診 22.6%、前 24h 達 70%；護理評估偵測 54% 需手術/EVD 之惡化）；高風險前 24h 常每小時一次，兼顧避免睡眠剝奪與 ICU 譫妄 |

## 2. 靜脈血栓（DVT / PE）預防與治療方案（Sec 5.3.3, e310–e312）

| 臨床階段與情境 | 具體建議內容 | COR / LOE | 關鍵試驗與備註 |
| :--- | :--- | :--- | :--- |
| **機械預防（無法行走）** | **確診當日即啟動 IPC（間歇性氣動壓縮）** | `COR 1, LOE B-R` | **CLOTS 3**（ICH 佔 13%）；住院 VTE ~7%（DVT 風險為 AIS 之 4 倍）；留意皮膚破損 |
| **單用漸進式彈性襪** | 及膝或及大腿彈性襪單用**無益** | `COR 3: No Benefit, LOE B-R` | **CLOTS 1 & 2** 與網絡統合分析 |
| **藥物預防（無法行走）** | 低劑量 UFH 或 LMWH 降 PE 風險（`COR 2a, C-LD`）；於**發病後 24–48 小時啟動**可能合理（`COR 2b, C-LD`） | `COR 2a / 2b, C-LD` | 1,000 例統合降 PE 且不顯著增 HE；**建議 24–48h 啟動前先以追蹤 CT 確認血腫穩定** |
| **急性 ICH 併近端 DVT（尚不適抗凝）** | 暫時置放**可回收式 IVC 濾網**作為橋接 | `COR 2a, LOE C-LD` | **RIETE 登錄**：降 PE 相關死亡，但增復發 VTE |
| **急性 ICH 併近端 DVT 或 PE 之治療抗凝** | 延遲 **1–2 週**再啟動治療劑量 UFH 或 LMWH 可考慮 | `COR 2b, LOE C-LD` | 源自創傷 ICH 研究（未擴大組中位 10 天 vs 擴大組 5.5 天），須個別權衡血腫大小、年齡與血栓範圍 |

## 3. 吞嚥、感染、心臟監測、血糖、體溫與癲癇速查（Sec 5.3.2, 5.3.5–5.3.6, 5.4）

| 系統項目 | 臨床處置建議 | COR / LOE | 關鍵數據與紅旗 |
| :--- | :--- | :--- | :--- |
| **吞嚥篩檢** | 經口進食前必行正式吞嚥篩檢流程 | `COR 1, B-NR` | 肺炎率 2.4% vs 5.4%（中風肺炎死亡率 ~35%） |
| **連續心臟監測** | 入院最初 **24–72 小時**連續心電圖監測 | `COR 2a, C-LD` | 25%–30% 發生顯著心律不整（病灶 >5 cm 風險高） |
| **感染評估** | 入院與住院全程視臨床需要作檢驗與影像評估 | `COR 2a, C-LD` | IVH 與 ICH score >2（OR 1.7）感染風險顯著上升；*註：前 24h 90% 符 SIRS 但血培養陽性率僅 0.1%* |
| **血糖控制** | 監測血糖（`COR 1`）；矯正**低血糖 `<40–60 mg/dL`（`COR 1`）**；治療**高血糖 `>180–200 mg/dL`（`COR 2a`）** | `COR 1` / `2a, C-LD` | **NICE-SUGAR**：嚴控 81–109 vs <180 增 90d 死亡與嚴重低血糖（6.8% vs 0.5%）；重度腦傷嚴控 80–110 致腦能量危機 |
| **體溫與低溫** | 藥物退燒可能合理（`COR 2b`）；治療性低溫（`<35°C`）減水腫效用不明（`COR 2b`） | `COR 2b, C-LD` | >30% 發生發燒；表面/導管恆溫裝置未改預後反增鎮靜/呼吸器/ICU 天數 |
| **臨床與電生理癲癇** | 臨床癲癇或意識障礙併確診電生理癲癇必給 **ASM**（`COR 1`）；不明意識波動做 **cEEG ≥24h**（`COR 2a`） | `COR 1` / `2a` | 28% 於 >24h 偵測、94% 於 48h 內偵測（昏迷者 36% 需 >24h）；CAVE 分數不得用於指導延長用藥 |
| **預防性抗癲癇藥** | **無癲癇證據者不應給預防性 ASM**（含 Phenytoin / Levetiracetam） | `COR 3: No Benefit, B-NR` | 未降早期（<14d）或長期癲癇、未改功能，恐損認知 |

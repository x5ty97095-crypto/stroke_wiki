# 中風病房住院支持照護與併發症預防

> [!tip] 臨床速查結論（Bottom Line）
> - **中風病房**：所有年齡 AIS 病患皆應入住具跨專業團隊與標準化流程之組織化中風病房（**COR 1, LOE B-R**，[[aha-asa-ais-2026|AHA/ASA AIS (2026)]] Sec 5.1）。
> - **吞嚥與營養**：任何經口進食/飲水前必做**床邊吞嚥篩檢**（COR 1），未過者行 **FEES 或 VFSS**（COR 2a）；**48h 內**營養篩檢、**7 天內**開始腸道營養（COR 1），前 7 天優先 **NG 管**，預期 >2–3 週無法安全吞嚥再置 **PEG**（COR 2a，FOOD 3）。
> - **吞嚥電刺激（PES）勘誤重點**：氣切脫離呼吸器後助拔管維持 **COR 2a**；**非氣切吞嚥障礙已依 2026/08 勘誤下修為 COR 2b**（STEPS Phase III 陰性）。
> - **DVT 預防**：行動受限者首選 **IPC**（**COR 1, LOE B-R**，CLOTS-3）；預防劑量 UFH/LMWH 降 VTE 為 COR 2a（降死亡率未確立 COR 2b）；**禁止使用漸進式彈性襪**（**COR 3: Harm**，CLOTS 1–2）。
> - **住院四大禁忌紅線（COR 3）**：禁止**漸進式彈性襪**（Harm）、禁止**常規留置導尿管**（Harm）、禁止**24h 內高劑量極早期下床活動**（Harm，AVERT）、不建議**常規預防性抗生素**（No Benefit）與**無憂鬱者用 SSRI 促動作恢復**（No Benefit）。

## 1. 中風病房住院照護核心檢核表（[[aha-asa-ais-2026|AHA/ASA AIS (2026)]] Sec 5.1–5.7）

| 照護面向 | 具體臨床建議 | COR / LOE | 關鍵試驗與注意事項 |
| :--- | :--- | :--- | :--- |
| **中風病房（Stroke Unit）** | 入住組織化中風病房（實體集中病房效益最顯著），採跨專業團隊與標準化醫囑 | `COR 1, LOE B-R` | Stroke Unit Trialists’ 2020（29 RCT, N=5902） |
| **吞嚥篩檢與評估** | 經口進食／飲水前必做床邊吞嚥篩檢（COR 1）；由語言治療師或受訓人員執行（COR 2a）；未過或無法配合者做 **FEES 或 VFSS**（COR 2a）；口腔衛生流程（COR 2b） | `COR 1 / 2a / 2b` | Sec 5.2（勘誤 #22 明確納入 VFSS） |
| **咽部電刺激（PES）** | **氣切且脫離呼吸器後**助拔管（FEES 評估）：`COR 2a, LOE B-R`；**非氣切吞嚥障礙**：`COR 2b, LOE B-R`（經 2026/08 勘誤下修） | `COR 2a`（氣切） / `COR 2b`（非氣切） | **STEPS** Phase III 陰性（P=0.60）；PHAST-TRAC 見名義死亡率升待驗證 |
| **營養篩檢與管灌** | **48h 內**以驗證工具（MNA/CONUT/GNRI/MUST）篩檢營養（COR 1）；**7 天內**開始腸道營養（COR 1）；吞嚥障礙前 7 天先用 **NG**，預期 >2–3 週再放 **PEG**（COR 2a） | `COR 1 / 2a` | **FOOD 1**（無吞嚥障礙加補充品無益）、**FOOD 2**（7 天內管灌降死亡趨勢 P=0.09）、**FOOD 3**（過早 PEG 預後較差） |
| **DVT 預防 — IPC** | 行動受限且無禁忌者，常規照護外加用**間歇性充氣加壓裝置（IPC）** | `COR 1, LOE B-R` | **CLOTS-3**（N=2876；30d 近端/症狀 DVT 8.5% vs 12.1%, RD −3.6%；皮膚破損 3% vs 1%） |
| **DVT 預防 — 藥物** | 預防劑量皮下 **UFH 或 LMWH** 降 VTE 為合理（COR 2a）；對整體存活效益未確立（COR 2b, LOE A）；LMWH vs UFH 孰優未確定（COR 2b） | `COR 2a / 2b` | 14 試驗統合：降 DVT (OR 0.21) / PE (OR 0.69)，但增 ICH (OR 1.68) 與顱外出血 (OR 1.65)；PREVAIL（Enoxaparin 40 mg QD vs UFH BID） |
| **中風後憂鬱（PSD）** | 結構化量表常規篩檢（前 2 個月 PHQ-9 較準、>2 個月 HDS 較準）；確診後以**抗憂鬱劑**及／或**非藥物治療**（心理治療、rTMS、針灸）治療 | `COR 1, LOE B-NR / B-R` | PSD 盛行率約 31%（Sec 5.5） |
| **緩和醫療轉介** | 視病患與家屬需求適時轉介安寧緩和醫療資源 | `COR 2a, LOE C-EO` | Sec 5.6 |
| **住院復健** | 住院期間（特別是入院 3 天內啟動）跨專業評估並提供個別化復健 | `COR 1, LOE A` | Sec 5.7 |

> [!danger] 住院照護明確禁止／不建議項目（Sec 5.4, 5.6, 5.7）
> 1. **漸進式彈性襪（Elastic / Graded Compression Stockings）**（**COR 3: Harm, LOE B-R**）：CLOTS 1（N=2518）與 CLOTS 2（N=3114）證實未減 DVT 且顯著增加皮膚破損、潰瘍與組織壞死（5% vs 1%）。
> 2. **常規置放留置導尿管**（**COR 3: Harm, LOE C-LD**）：顯著增加 CAUTI 並與 3 個月不良預後獨立相關，應避免或儘早拔除。
> 3. **發病 24 小時內高劑量極早期下床活動**（**COR 3: Harm, LOE B-R**）：**AVERT**（N=2104）證實降低 3 個月良好功能預後（mRS 0–2：46% vs 50%, aOR 0.73, P=0.004）。
> 4. **常規預防性抗生素**（**COR 3: No Benefit, LOE A**）：PASS、STROKE-INF、PRECIOUS 均證實不改善 90d mRS 且不減少肺炎。
> 5. **無憂鬱者使用 SSRI 促運動恢復**（**COR 3: No Benefit, LOE A**）：Cochrane（>13,000 人）無動作或獨立性獲益，且增加骨折、跌倒（3% vs 1%）與癲癇（2% vs <1%）。
